🎮 Hangman Game (Java)
Welcome to my Java Hangman Game, a beginner-friendly command-line game where the player guesses a hidden word one letter at a time. I built this project while self-learning Java and practicing basic programming concepts.

📚 About
This is a console-based implementation of the classic Hangman game.

🔤 Features include:

- Random word selection from a predefined list

- Case-insensitive guessing

- Input validation (only allows single characters)

- Tracks number of attempts and guesses left

- Win and lose conditions

- Option to play again after each round

This project helped me understand how to:

- Use Java arrays and loops

- Handle user input with Scanner

- Write and call custom methods

- Track game state (e.g. guesses left, word progress)

- Organize logic into manageable chunks

💻 How to Run
You'll need:

Java installed on your computer (javac and java in your terminal)

Steps:
1. Clone the repository:
   git clone https://github.com/Tignaman88/Hangman.git
2. Navigate into the project folder:
   cd HangmanProject
3. Compile the Java file:
   javac Hangman.java
4. Run the game:
   java Hangman
